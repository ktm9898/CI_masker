# 재무제표 PDF/이미지 마스킹 도구 (Client-Side)

재무제표(PDF, JPG, PNG)에서 업체명, 법인번호, 사업자번호를 자동으로 감지하여 마스킹(검정 박스 처리)하는 웹 도구입니다.

## 🚀 주요 기능
- **자동 감지**: 사업자번호, 법인번호, 업체명(상호/법인명 레이블 기반) 자동 인식
- **이미지 지원 (OCR)**: Tesseract.js를 사용하여 이미지 파일 내 텍스트 인식 및 마스킹
- **스캔 PDF 지원**: 텍스트 레이어가 없는 스캔본 PDF의 경우 OCR Fallback 모드 작동
- **수동 추가**: 자동 감지되지 않은 텍스트를 직접 입력하여 추가 마스킹 가능
- **100% 로컬 처리**: 모든 데이터는 브라우저 내에서만 처리되며 서버로 전송되지 않습니다.

## 🛠 사용 방법 (GitHub Pages 기준)
1. 이 레포지토리를 GitHub에 업로드합니다.
2. 설정(Settings) -> Pages 메뉴에서 `main` 브랜치를 소스로 선택하여 배포합니다.
3. 생성된 URL에 접속하여 즉시 사용 가능합니다.

## 🔒 보안 및 개인정보 보호
본 애플리케이션은 **Client-Side Processing Only** 원칙에 따라 설계되었습니다.
- PDF 및 이미지 분석은 사용자의 기기(CPU/GPU)에서 수행됩니다.
- 외부 API 서버로 데이터를 전송하지 않습니다.
- 오픈 소스로 공개되어 있으므로 로직을 직접 검증하실 수 있습니다.
